# beyejin archive

학습·실험·이전 버전 레포의 최신 스냅샷과 원본 링크를 모아둔 개인 보관소입니다.

## 보관 원칙

- 스냅샷 기준일: 2026-08-27
- 각 스냅샷은 원본 레포의 기본 브랜치 최신 커밋에서 가져왔습니다.
- 원본 레포는 삭제하지 않고 Archived 상태로 유지해 URL과 전체 커밋 이력을 보존합니다.
- fork 레포는 upstream 코드와 라이선스가 섞일 수 있으므로 이 저장소에 복사하지 않습니다.
- 나중에 다시 사용할 때는 원본 레포에서 작업을 재개하고, 이 저장소는 당시 상태를 확인하는 참고본으로 사용합니다.

## 이번에 보류한 레포

- [beyejin/learning-github](https://github.com/beyejin/learning-github): 열린 Dependabot PR #1이 있어 원본 Archived 처리를 보류했습니다.
- fork 레포와 현재 사용 여부를 확인하지 못한 개인 프로젝트는 이 저장소에 복사하지 않았습니다.

## 다시 사용하고 싶을 때

원본 레포의 URL에서 커밋 이력을 그대로 확인하고, GitHub 저장소 설정에서 Archived 상태를 해제한 뒤 작업을 재개합니다. 이 저장소의 스냅샷은 원본을 대체하지 않습니다.
